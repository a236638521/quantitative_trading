# AlphaQuant A股全栈量化策略研究与回测系统

基于 **Python 3.12 + FastAPI + ECharts** 构建的专业 A 股量化研究、回测与分析全栈系统。严格贴合 A 股交易规则，内置数据采集、本地秒级缓存、高精度撮合引擎与现代化 Web 交互看板。

---

## 核心特性与 A 股规则内嵌

1. **A股特定交易规则严格撮合**：
   - **T+1 制度**：当日买入的股票/ETF当日不可卖出，次日自动转为可用持仓。
   - **一手 100 股限制**：买入必须为 100 股整数倍，资金不足时自动向下取整撮合；卖出支持零股清仓。
   - **涨跌停限制**：主板 10%、创业板/科创板 20%、ST 5%。封死涨停时买单自动被拒，封死跌停时卖单自动被拒。
   - **真实规费与成本模型**：包含双向佣金（默认万2.5，单笔最低5元）、卖出单边印花税（万5）、过户费（万0.1）与自定义滑点损耗。

2. **高性能数据中心与缓存**：
   - 集成 **Baostock / AkShare**，支持全市场 A 股、主流 ETF 与宽基指数（沪深300/中证500/中证1000）的前复权历史 K 线。
   - 内置 **Parquet 高速列式缓存**，首次下载后本地秒级加载回测。

3. **完备的量化评估体系**：
   - 累计收益率 (Total Return)、年化收益率 (Annualized Return)、基准收益与 Alpha / Beta。
   - 风险收益指标：夏普比率 (Sharpe)、索提诺比率 (Sortino)、最大回撤 (Max Drawdown)、卡玛比率 (Calmar)、年化波动率。
   - 交易统计：交易笔数、胜率 (Win Rate)、盈亏比 (Profit/Loss Ratio)、盈利/亏损次数。

4. **预置经典量化策略库**：
   - **双均线交叉策略 (Dual Moving Average)**：快慢均线金叉建仓、死叉平仓，趋势跟踪。
   - **海龟唐奇安突破策略 (Turtle Breakout)**：突破 20 日高点入场，跌破 10 日低点离场，结合 ATR 波动。
   - **布林带均值回归策略 (Bollinger Bands Grid)**：触碰下轨超跌建仓，触碰上轨超买止盈，适合震荡市与 ETF 网格。

5. **现代暗黑金融终端看板**：
   - 策略净值与沪深300基准对比曲线（带缩放轴与水下回撤联动）。
   - 标的 K 线蜡烛图与买卖点标记（Buy/Sell 标记精确打点到执行 K 线）。
   - 水下动态回撤面积图。
   - 成交明细表（含每笔费用、已实现盈亏与账户余额）与引擎逐日运行日志。

## 启动与使用指南

### 1. 激活虚拟环境
在项目根目录下打开命令行：
```powershell
.\.venv\Scripts\Activate.ps1
```

### 2. 启动量化平台服务
```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

### 3. 打开 Web 控制台
在任意浏览器中访问：
👉 **http://127.0.0.1:8000**

即可查看并使用：
- **标的速选**：一键切换 510300 沪深300ETF、600519 贵州茅台、000001 平安银行、300750 宁德时代等；
- **在线调参**：动态调整快慢线周期、入场出场周期、仓位比例等参数；
- **回测分析**：点击【运行量化回测】，实时查看净值曲线、夏普比率、胜率及 K 线买卖打点。
